# Node.js Project

Proyecto básico de Node.js para trabajar con JavaScript por consola.

## Instalación

Este proyecto usa Node.js v22.14.0 y npm 10.9.2

No requiere dependencias adicionales para empezar.

## Uso

Para ejecutar el proyecto:

```bash
node index.js
```

O usando el script definido:

```bash
npm start
```

## Estructura del proyecto

- `index.js` - Archivo principal con ejemplos de código
- `package.json` - Configuración del proyecto
- `.gitignore` - Archivos ignorados por git

## Desarrollar

Puedes editar el archivo `index.js` para agregar tu propio código JavaScript.
